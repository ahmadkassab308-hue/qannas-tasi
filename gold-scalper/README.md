# بوت سكالبينج لحظي للذهب (MT5)

## التركيب
1. افتح MetaTrader 5، ثم File > Open Data Folder.
2. انسخ `GoldTickScalper.mq5` إلى `MQL5/Experts`.
3. افتحه في MetaEditor واضغط Compile.
4. اسحبه على شارت XAUUSD وفعّل Algo Trading.

## آلية العمل
يقيس حركة السعر في آخر عدة تكات. إذا تجاوزت الحركة الحد يدخل باتجاهها،
ويغلق فور تحقيق الربح المستهدف، أو عند وقف الخسارة، أو بعد مهلة أقصاها 800 مللي ثانية.
وقف خسارة احتياطي يوضع على الصفقة نفسها لدى الوسيط في حال انقطاع الاتصال.

## حدود الأمان
حد خسارة يومي، حد لعدد الصفقات، فلتر للسبريد، وفترة انتظار بين الصفقات.
